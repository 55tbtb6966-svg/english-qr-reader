# English QR Reader

QRコードをiPhoneで読み取り、英語を表示・読み上げするWebアプリです。

## QRコードの内容

次のどちらかにします。

- 英語だけ  
  `apple`

- 英語と日本語  
  `This is an apple.|これはリンゴです。`

`|` の前だけを英語音声で読み上げます。

## Windowsで確認する

1. フォルダを展開します。
2. `index.html` をダブルクリックします。
3. 下部の「Windowsでの動作確認用」に英文を入力します。
4. 「この文章を表示して読む」を押します。

ローカルファイルから開いた場合、カメラ機能は動きません。

## iPhoneでカメラを使う

カメラを使うには、HTTPS対応のWeb公開サービスへ置く必要があります。
GitHub Pagesなどへ、フォルダ内のファイルをそのままアップロードしてください。

公開後：
1. iPhoneのSafariでURLを開く
2. 「QRコードを読み取る」を押す
3. カメラ利用を許可する
4. 必要なら共有ボタンから「ホーム画面に追加」

## 注意

QR読み取りライブラリはCDNから読み込みます。そのため、初回のQR読み取り時は
インターネット接続が必要です。読み上げはiPhoneの音声合成機能を使用します。
