# English QR Reader IndexedDB 日本語読み改善版

## 日本語の自然さを改善する方法

CSVに `JapaneseRead` 列を追加しました。

- `Japanese`：画面に表示する日本語
- `JapaneseRead`：実際に読み上げる日本語。ひらがな、空白、句読点で調整します。

例：

ID,English,Japanese,JapaneseRead,Mode,EnglishRate,JapaneseRate,Repeat,Gap,Version
E000001,This is an apple.,これはリンゴです。,これは りんご です。,both,1.0,0.9,1,0.7,2026-08-01

`JapaneseRead` が空欄なら、`Japanese`をそのまま読み上げます。

アプリ内で利用可能な日本語音声も選択できます。


## 漢字列と読み列の表示

読み取り画面では次の両方を表示します。

- 表示用日本語（漢字）：`Japanese`
- 日本語読み：`JapaneseRead`

一括QRカードにも漢字と読みの両方を表示します。


## QRカードの表示内容

一括QR作成画面で、次の3種類から選択できます。

- 英語＋ひらがな
- 英語のみ
- ひらがなのみ

ひらがな表示には `JapaneseRead` を使用します。空欄の場合は `Japanese` を表示します。

## QR読み取り直後の音声改善

カメラ停止直後に約0.5秒待ってから再生し、iOS Safariで先頭音声が途切れにくいようにしました。
また、音声キャンセル直後にも短い待機を入れています。


## QR表示件数とページ切り替え

一括QR作成では、1ページあたり次の件数を選べます。

- 6件
- 8件
- 10件
- 12件
- 20件
- 30件
- 50件

「前のページ」「次のページ」で、選択した件数単位に切り替えられます。


## 音声開始前のポーズ強化

iPhone Safariで先頭音が欠ける場合への対策として、次を追加しました。

- QR読み取り後、カメラ停止から約1秒待って再生
- `speechSynthesis.cancel()`後に約0.35秒待機
- 各音声の直前に無音の準備音＋約0.25秒の待機

以前より再生開始は少し遅くなりますが、先頭音が欠けにくくなります。


## 音声開始時の圧迫音・ポップ音対策

無音の `SpeechSynthesisUtterance` を先に再生する方式を削除しました。
iPhoneでは、無音でも音声出力経路の切り替え時に「ポッ」という音や圧迫感が生じることがあるためです。

現在は次の待機だけを使います。

- カメラ停止後：約0.9秒
- 音声キャンセル後：約0.3秒
- 実際の音声開始前：約0.35秒

無音音声は再生しません。


## 発音記号（IPA）

CSVに `IPA` 列を追加しました。

- 単語・語彙項目：IPAを入力
- 例文：空欄
- 読み取り画面：「発音記号を表示」のON/OFF
- QRカード：「発音記号を表示」のON/OFF
- IPAは読み上げには使用せず、表示専用です

今回のサンプルCSVは米国英語のIPAで統一しています。


## QRカードのID表示

一括QR作成画面で「IDを表示」をON/OFFできます。

- ON：QRコードの下にIDを表示
- OFF：QRコード、英語、ひらがな、発音記号のみ表示

初期設定はONです。


## QR表示設定の配置改善

「発音記号を表示」と「IDを表示」を、同じ設定枠の中に整理しました。

- PC・横画面：横並び
- iPhoneなど狭い画面：縦並び
- チェックボックスの大きさと間隔を統一


## QRサイズと文字サイズ

- QRコード：150pxから132pxへ縮小
- 英語、発音記号、ひらがな、ID：文字を拡大
- 印刷時はQRを124pxに調整し、文字の読みやすさを優先


## 詳細設定（QR・文字サイズ）

QR作成画面の折りたたみ式「詳細設定」から、次を変更できます。

- QRコードサイズ
- ID文字サイズ
- 英語文字サイズ
- 発音記号サイズ
- ひらがな文字サイズ

設定は `localStorage` に保存され、同じiPhone・同じSafariサイトでは次回も維持されます。
「初期値に戻す」で標準サイズへ戻せます。


## 単語1語の開始音対策

iPhoneで単語1語の先頭に「息を吹きかけられたような音」やポップ音を感じる場合への対策です。

- 発話中でない場合は `speechSynthesis.cancel()` を実行しません
- 英単語1語だけの場合、同じ発話の先頭に短い句読点ポーズを入れます
- 単語1語の音量を 0.82 に抑えます
- 別の無音発話は使用しません
- 詳細設定から「単語1語のソフトスタート」をOFFにもできます

これはハウリング対策ではなく、iPhone Safariの音声出力開始時のポップ音・破裂音を目立ちにくくする調整です。


## 短い英語表現にも適用

ソフトスタートの対象を、英単語1語だけでなく次のような短い表現まで広げました。

- `bathtub`
- `Good morning.`
- `washing machine`
- `rice cooker`

対象条件は、英語1～3語かつ概ね28文字以内です。
長い例文には適用しません。


## バージョン表示

画面右上に小さくバージョンを表示します。

- アプリ版：`v1.9.0`
- CSVにVersionがある場合：`App v1.9.0 / CSV 2026-08-01` のように表示
- 印刷時は非表示


## 短い英語に変な言葉が入る問題の修正

以前は短い英語の先頭に `…` を付けて、同じ発話内にポーズを作っていました。
iPhoneの音声によっては、この記号を音声として解釈することがあるため削除しました。

現在は次の処理だけを行います。

- 読み上げる文字列はCSVの英語そのもの
- 短い英語は再生前に約0.65秒待機
- 短い英語の音量は0.9
- 句読点や無音文字などは追加しない


## 英語音声の選択

読み上げ設定に「英語音声」を追加しました。

- iPhone SafariがWebページへ公開している英語音声から選択
- 選択内容は同じiPhoneのSafari内に保存
- 次回起動時も同じ音声を使用
- 日本語音声の選択も保存

iPhone本体に複数の音声があっても、Safari側に公開されない音声は一覧に表示されない場合があります。
